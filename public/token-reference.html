Buttons — hold

WIP
WIP — don't build production button tokens yet. Variants (primary / secondary / tertiary / destructive / subtle), their states, and the focus treatment are still being refined in the guidelines. Values may change. Set up the empty variant structure if you like, but don't harden the colors.

Dark mode — later

LATER
Dark-mode semantic + component tokens are already specified and delivered, but implementation is scheduled after the light-mode refactor. Primitives above already cover dark mode (surfaces come from Forest 700–900, accents lighten to the 300–400 steps) — no new primitives needed when you get to it.
